# blender-aarch64-build

Agent skill (SKILL.md) for building Blender from source on aarch64 Linux (NVIDIA DGX Spark / GB10, Ubuntu 24.04),
with every dependency and toolchain fix hit along the way. Verified with Blender 5.2.3 LTS + CUDA 13 Cycles.

Install: copy `blender-aarch64-build/` into `~/.agents/skills/`.
